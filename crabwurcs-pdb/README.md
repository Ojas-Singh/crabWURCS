PDB/mmCIF glycan extraction for the crabWURCS project.

## Overview

Every monosaccharide is read from its 3D coordinates, whatever its residue
is called:

- **Rings and numbering from the bond graph**: bonds perceived from distances
  within each atom's valence, plus `CONECT`/`LINK` records
- **Configuration from signed volumes**: every stereocentre, so D/L, the
  parent sugar, deoxy positions and uronic acids; the anomer against the
  anomeric reference atom
- **Substituents and linkages from bonded atoms**: N-acetyl, N-glycolyl,
  N-sulfate, O-sulfate, phosphate, phosphocholine, O-methyl, O-acetyl, in the
  same residue or in residues of their own (GLYCAM `SO3`, `MEX`, `ACX`, `PCX`)
- **Names as hints**: the pinned wwPDB CCD component table, registry names and
  GLYCAM codes fill in what the coordinates cannot show (missing atoms, a
  centre too flat to read); every disagreement is a `PdbWarning`, and
  `NamePolicy` chooses what decides (`Coordinates`, `Names`, `Strict`)

## Usage

```rust
use crabwurcs_core::write_wurcs;
use crabwurcs_pdb::{PdbReadOptions, read_glycans_from_file};
use std::path::Path;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let reading = read_glycans_from_file(Path::new("glycan.pdb"), &PdbReadOptions::default())?;
    for glycan in &reading.glycans {
        println!("Extracted: {}", write_wurcs(&glycan.graph)?);
        println!("Source residues: {:?}", glycan.residues);
    }
    for warning in &reading.warnings {
        // residue 2uA A:4: named α-L-IdopA, coordinates say α-L-GulpA2S (C2)
        eprintln!("warning: {warning}");
    }
    Ok(())
}
```

`extract_glycans_from_file` and the other `extract_glycans_*` functions read
the same way and return the glycans only.

## Testing

- wwPDB CCD coordinates of 49 components (ideal and model) read as their CCD
  names under neutral, real, misleading and mirrored names
  (`tests/data/ccd_stereo_references.tsv`, regenerated by
  `cargo run -p crabwurcs-pdb --example regenerate_ccd_stereo_references`)
- Heparin 1HPN and 3IRJ (first models) read as one sulfated glycan each
- Opt-in: every GlycoShape Level 1 file against its entry name and the entry
  audit, and ring by ring against an independent coordinate reader
  (`tests/glycoshape_coordinates.rs`)
